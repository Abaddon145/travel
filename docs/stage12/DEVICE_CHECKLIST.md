# 真机验收清单

自动化覆盖了 WebKit 的 iPhone 14 描述（安全区、`100dvh`、内部滚动、输入框 16px、`display-mode: standalone` 样式）。下面这些要在一台真实 iPhone 的 Safari 上做。生产地址是 `https://lvxu-ai-travel.lvxu.workers.dev`。合并到 `main` 并等 GitHub Actions 部署成功后再测。

每一项做完把 `- [ ]` 改成 `- [x]`。不要把私人密钥、DeepSeek 密钥或高德密钥写进这份清单或截图。

- [ ] 添加到主屏幕。用 Safari 打开生产地址，分享菜单选「添加到主屏幕」。图标不透明，名称是「旅序」。从主屏幕打开后没有 Safari 工具栏，状态栏区域不挡住标题。
  - 预期：独立窗口，顶部标题完整，底部导航不被横条挡住。

- [ ] 门禁登录。在「我的」填入私人密钥并验证。错误密钥不能生成行程。正确密钥后云端接口显示已连接。
  - 预期：付费按钮在未通过时不会改行程；通过后可以打开生成页。密钥不出现在地址栏或另一台设备上。

- [ ] 核心流程。新建一趟行程，修改标题，加一天，加一个景点，锁定它，刷新后仍在，且锁定项不能编辑或删除。
  - 预期：刷新和从主屏幕重新打开后，标题、景点和锁定状态都还在。

- [ ] AI 起草。用一次生成，先看预览，再保存。故意在离线时点生成。
  - 预期：未保存前行程列表不变。保存后能打开草稿。离线时按钮不可用，并说明需要网络。不要连续重试，以免碰到每日 30 次上限。

- [ ] 锁定后的局部重排与撤销。打开助手，对含锁定项的一天提一个调整，确认差异里没有锁定项，应用后再撤销。
  - 预期：锁定的景点或住宿原文还在。撤销后备注回到应用前。关闭助手再打开，对话可以不在；已应用的修改仍能从版本记录恢复。

- [ ] 地图。展开地图，核对一个地点，再核实一段步行。没有结果时不显示估算距离。
  - 预期：只有高德返回并确认后才出现「已核对」和米数。失败时行程本身还在。

- [ ] 预算合计。打开有示例账的行程，看预计、实际和差额。
  - 预期：同一币种加总，人民币与其他币种不混成一个数。

- [ ] 预订与清单。加一条住宿和一条清单，杀掉进程后再从主屏幕打开。
  - 预期：两条都还在这台手机上。

- [ ] 断网冷启动。系统设置里关掉无线和蜂窝，从主屏幕冷启动（先划掉进程）。
  - 预期：外壳能打开，已保存的行程能看。生成、助手、地图核对和云端接口说明需要网络，不报一串缓存下来的鉴权结果。

- [ ] 备份恢复。在「我的」导出 JSON，用隔空投送或文件 App 存到别处。删掉这台设备上的站点数据后，再导入该文件，选择合并或替换并确认。
  - 预期：导入前有预览。确认后行程、预算和清单回来。文件里没有私人密钥。

- [ ] 打印 PDF。打开一趟行程的「攻略」，点「打印或存储为 PDF」，在打印面板里存储为 PDF。
  - 预期：PDF 含日程，空的章节有说明。界面导航不进 PDF。

- [ ] 深浅色切换。在「我的」切换浅色和深色，再跟随系统改一次。
  - 预期：背景、文字和状态栏主题色跟着变，文字仍可读，焦点环看得见。

- [ ] 更新提示。下一次部署之后，从主屏幕打开已安装的旅序，切到前台停留一会儿。
  - 预期：底部出现「有新版本」。点「稍后」可以继续当前操作。点「刷新」后才换成新外壳。
